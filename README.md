# Weather App

A simple and responsive weather application that allows users to search for cities and access real-time weather information.

The application provides a search system with autocomplete suggestions, allowing users to quickly find locations. After selecting a city, the current weather data is displayed, including temperature, weather conditions, wind speed and air humidity.

## Live Demo

You can access the deployed application here:

https://weather-app-henna-xi-44.vercel.app/

## Features

- City search with autocomplete suggestions
- Real-time weather information
- Current temperature display
- Weather condition information (clear sky, rain, clouds, etc.)
- Wind speed data
- Air humidity information
- Location-based weather data

## Technologies

### Frontend

- React
- Vite
- Tailwind CSS

### Backend

- Node.js
- Express.js

### API

- OpenWeatherMap API

The application uses the OpenWeatherMap API to retrieve geographic information and real-time weather data for searched locations.

## Architecture

The project is divided into two main parts:

The frontend is responsible for the user interface and interaction, while the backend handles communication with the OpenWeatherMap API and manages API requests.
